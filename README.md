# Мурзабекова Айжамал — сайт-портфолио учителя начальных классов (г. Ош)

Сайт на React + Vite + Tailwind с сервером на Express: методическая копилка, достижения,
галерея, отзывы с модерацией, онлайн-запись на консультацию, ИИ-помощник (Gemini) и
скрытая админ-панель.

## Запуск

```bash
npm install
cp .env.example .env      # и заполните значения
npm run dev               # http://localhost:3000
```

Продакшн:

```bash
npm run build
npm start                 # NODE_ENV=production, порт из PORT (по умолчанию 3000)
```

## Админ-панель

Админ-панель скрыта: на сайте нет кнопки или ссылки на неё. Чтобы открыть её, перейдите по адресу **`ваш-сайт/#admin`** и введите пароль из переменной
`ADMIN_PASSWORD`. Без этой переменной войти нельзя.

В панели:

- **Заявки родителей**: статусы, личные заметки, кнопки «WhatsApp» и «Позвонить», удаление.
- **Отзывы**: новые отзывы появляются на сайте только после нажатия «Опубликовать».
- **Активность**: посещения за 7 дней, скачивания и вопросы ИИ-помощнику.
- **Интеграции**: статус Telegram и Gemini, кнопка тестового сообщения в Telegram.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `ADMIN_PASSWORD` | Пароль админ-панели (обязательно) |
| `GEMINI_API_KEY` | ИИ-помощник; без ключа бот отвечает заготовленным текстом |
| `GEMINI_MODEL` | Модель Gemini, по умолчанию `gemini-flash-latest` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления о новых заявках и отзывах в Telegram |
| `DATA_DIR` | Папка для `db.json` с заявками и отзывами (по умолчанию `./data`) |

Заявки и отзывы хранятся в `data/db.json`. На хостинге без постоянного диска
(например, Cloud Run) укажите `DATA_DIR` на подключённый том, иначе данные будут
теряться при перезапуске.

## Что нужно заполнить вручную

Все тексты и личные данные находятся в `src/data/content.ts`:

- **Контакты** (`schoolContactDetails`): сейчас там образцы. Укажите настоящий телефон, WhatsApp, Telegram и почту.
- **Фото**: положите фото учителя в `public/teacher-photo.jpg`. Пока его нет, на сайте показываются инициалы.
- **Биография, образование, награды, статистика, методические материалы**: проверьте, что всё соответствует действительности.
- **Фото галереи**: сейчас это стоковые картинки с Unsplash. Замените их на настоящие фото класса.
